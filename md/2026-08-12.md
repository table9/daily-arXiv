### SABRE Hyperpolarization of Unmodified Amino Acids in Partially Aqueous Media: L-[1-13C]-Valine as a Model System

The dependence of polarization on parahydrogen bubbling time, solvent composition, and substrate-to-catalyst ratio was investigated.

### Compression of virtual spaces in transcorrelated methods via singular value decomposition: application to the G2 set
- **arXiv**: [2608.10658](https://arxiv.org/abs/2608.10658)  ·  [PDF](https://arxiv.org/pdf/2608.10658.pdf)
- **Title (EN)**: Compression of virtual spaces in transcorrelated methods via singular value decomposition: application to the G2 set
- **Authors**: Yifan Cheng, Kristoffer Simula, Johannes Hauskrecht, Evelin Martine Corvid Christlmaier, Daniel Kats, Ali Alavi
- **Categories**: physics.chem-ph
- **TL;DR**: 本文提出一种基于奇异值分解（SVD）的虚拟空间压缩方案（SVD-TC），用于转相关（TC）计算。该方法将大基组下的正则虚拟轨道通过SVD投影到小基组上，从而在保持大基组精度的同时，仅需小虚拟空间的代价即可完成TC积分和post-HF相关计算（如CCSD(T)）。作者在G2-1基准集（55个分子）上应用SVD-xTC-CCSD(T)计算原子化能，结果与SHCI参考值及实验对比，表明三-zeta基组即可达到化学精度。

We introduce a new singular-value-decomposition-based scheme for constructing small virtual spaces out of large basis sets for transcorrelated (TC) calculations, termed SVD-TC. This work builds on the recent finding that the residual basis error in the TC reference energy converges more slowly than that of the correlation energy. Within the new workflow, the post Hartree-Fock TC calculation is performed in a compressed virtual orbital subspace, obtained by projecting the canonical virtual orbitals from a large basis set onto a smaller basis set through singular value decomposition (SVD). This allows us to achieve the high accuracy allowed by the large basis, whilst the bottleneck steps - TC integral calculation and post-HF correlation method such as CCSD(T) - incur the cost of only a small virtual space calculation. The method therefore is highly efficient, whilst avoiding the composite nature of the reference correction method. We compare our results against the near-exact semistochastic heat-bath configuration interaction (SHCI) reference values and experiment. We find that SVD-xTC-CCSD(T) delivers chemical accuracy already with triple-$ζ$ basis sets. Finally, we use the quadruple-$ζ$ results to analyze the accuracy of pseudopotentials within the TC method, and show that pseudopotential TC workflow provides faster basis-set convergence than all-electron TC. We also present timings for computing the atomization energies on G2-1 set, demonstrating the efficiency of our TC workflows.
