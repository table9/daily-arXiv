### LatticeMind: A Validation-Gated Agentic Framework for Density Functional Theory Workflows
- **arXiv**: [2610.26869](https://arxiv.org/abs/2610.26869)  ·  [PDF](https://arxiv.org/pdf/2610.26869.pdf)
- **Title (EN)**: LatticeMind: A Validation-Gated Agentic Framework for Density Functional Theory Workflows
- **Authors**: Nathaniel M. Vegh, Yu Zhu, Raphaël J. Prentki, Félix Beaudoin, Shuaishuai Yuan, Hong Guo
- **Categories**: cond-mat.mtrl-sci, cs.LG, physics.comp-ph, quant-ph
- **TL;DR**: LatticeMind 是一个"验证门控"的智能体框架，把自然语言请求转换为可执行、可检验的 DFT 多阶段工作流项目：先由工作流契约定义所需阶段、文件与依赖，再由确定性校验器在调用求解器前检查，失败时进行有界修复，并可追溯至项目文件。

First-principles calculations are rarely single solver calls: they are multistage workflows in which structures, settings, and saved densities must pass correctly between dependent stages. Language models can write a valid single input, but reliability collapses once stages are chained: a dropped dependency, wrong file handoff, or hallucinated keyword can invalidate results even when the solver runs, and such errors surface only after costly execution. We introduce LatticeMind, a validation-gated agentic framework that converts natural-language requests into executable, checkable density functional theory (DFT) projects. A workflow contract specifies required stages, files, and dependencies; deterministic validators inspect the project before any solver launch; failed checks trigger bounded repair; and reports remain traceable to project files. On a 44-case RESCU benchmark spanning total-energy, density-of-states, band-structure, magnetic, phonon workflows, three non-flagship LLM backends reproduced every reference value; 119 of 132 runs passed on the first validated plan and the rest after one repair cycle. Ablations identify the workflow contract and pre-execution validation as the principal reliability mechanisms; a conventional trial-and-repair baseline reaches 71% at twice the token cost per success. The same architecture reproduces every reference value on a 19-case VASP benchmark, demonstrating transfer across solvers. Beyond these task families, LatticeMind generated and validated the 23 inputs of a multistage study of Rh-induced electronic responses at a Rh$_6$/In$_x$Ga$_{1-x}$N photocatalyst interface. These results establish workflow contracts, deterministic validation, bounded repair, and traceable records as a practical foundation for reliable AI-assisted scientific computing, where preventable errors are caught before execution and the solver is never the first validator.
